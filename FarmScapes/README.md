# 🌾 FarmScapes

A C++ / C# game built with Visual Studio 2013.

## 📖 About the Game
FarmScapes is a 2D farming simulator that immerses the player in a rural lifestyle. 

Core Features
• Farming crops: farming crops in the mainland initially such as rice,paddy & selling it to
buy higher level equipment and progress to new levels.

## 🛠️ Built With
* **IDE:** Visual Studio 2013
* **Language:** C++ / C#
